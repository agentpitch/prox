# pitchProx v0.50.0 (Rust)

Стабильная сборка pitchProx на Rust для Windows x64. Она использует существующий
WebUI, форматы конфигурации и истории. В полном ZIP есть `pitchProx.exe` и
WinDivert 2.2.2. Суммы SHA-256 и манифест сборки доступны отдельно.

## Обновление с Go

В WebUI откройте «Настройки → Обновления», проверьте наличие обновлений и
нажмите «Установить» у `v0.50.0`. Встроенный обновлятор заменяет EXE и
перезапускает pitchProx, сохраняя конфигурацию и историю. В каталоге установки
должны быть совместимые файлы WinDivert 2.2.2.

Если в вашей версии встроенное обновление недоступно, остановите pitchProx,
распакуйте `pitchProx-windows-amd64.zip` и замените `pitchProx.exe`,
`WinDivert.dll` и `WinDivert64.sys` в каталоге установки. Сохраните файлы
конфигурации и истории.

Сравнение расхода ресурсов и покрытие проверок описаны в [rust/README.md](https://github.com/agentpitch/prox/blob/v0.50.0/rust/README.md).
На хосте сборки проверены настольный запуск и смена EXE. Сквозной перехват
трафика WinDivert и переход службы через Windows SCM требуют проверки
с правами администратора.
