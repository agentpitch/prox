# pitchProx v0.60.0 (Rust)

Для установки на Windows x64 достаточно `pitchProx.exe`. Rust обращается
напрямую к драйверу WinDivert 2.2.2. Подписанный `WinDivert64.sys` встроен
в EXE. При первом включении прозрачного перехвата приложение извлекает
драйвер рядом с собой, если файла ещё нет. `WinDivert.dll` для работы не
требуется. Перехват по-прежнему требует прав администратора.

## Обновление

В Rust v0.50.0 и в Go-версиях со встроенным обновлятором откройте
«Настройки → Обновления» и установите `v0.60.0`. Обновлятор заменяет EXE,
сохраняя конфигурацию и историю. Если обновление через приложение недоступно,
остановите pitchProx и замените `pitchProx.exe` в каталоге установки.

ZIP содержит тот же EXE, лицензионные уведомления и манифест. Команда
`pitchProx.exe windivert-license` показывает лицензию и исходники WinDivert.

## Расход ресурсов

В тесте с активным перехватом, четырьмя TCP-туннелями и скоростью 8,93 МиБ/с
медиана CPU приложения отличалась от Rust v0.50.0 на −0,1%. Private bytes
выросли на 34 КиБ, working set — на 46 КиБ. Сравнение проводилось на сборке
с тем же сетевым кодом и драйвером до присвоения номера v0.60.0.
